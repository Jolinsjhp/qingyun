# 青云 · Qingyun

面向 AI 编程初学者的学习工具，寓意“青云直上”。短期目标是 2027-01-31 前推进工作或实习机会；长期职业规划与首份工作薪资分开。不保证录用或特定薪资。

## 启动

运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开 http://localhost:8765 。无需安装项目依赖或提供 API key。

## 学习与职业路线

- 33 个中文微课：Python、算法、概率、Agent、SDD 与求职。
- 9 份精选原文（1 篇工程文章、8 篇论文）拆成 18 张每日 Agent 阅读卡；解释、原文、自测、实践与笔记。
- 57 项代码任务：5 个 Python 热身、30 道算法、14 道 SQL、8 个 Agent 项目关卡；最后两周重做与模拟面试。
- 35 个任务可在浏览器运行公开 Python 测试，支持逐例反馈、代码草稿、提交证据和重做日期；其他题型及 SQL 在 LeetCode 原站验证。
- 今日学习配方可直接打开六种练习模块，显示本轮题数和进度。自测答对后 1.2 秒自动下一题，答错停留解释并可重试；可随时暂停自动跳题。代码需公开测试全通过，原站题需手动确认通过；阅读需自测通过并保存至少 20 字笔记。项目与求职模块自测完成后进入实际任务。
- 变量课的 hello.py、分钟计算器、累加练习及有对应题单的算法课，提供“直接写代码”入口。hello.py 按三项输出标签和非空内容检查；编辑器可下载含题目、草稿和运行记录的 `.ipynb` 文件，在 Jupyter 中继续学习。
- 8 个视频 / 课程入口、7 个 GitHub 作者 / 团队推荐，每项附阶段与动手任务。
- AI 落地 + 编程、商分优先、开发优先三种每日配方，各 180 分钟。
- 伦敦岗位策略、运营案例证据、长期 £100k 职业路线与有明确适用范围的薪资来源。
- 选择题历史、错题与间隔复习；自定义知识卡；项目检查、岗位记录、SDD 工坊、JSON 备份和确认重置。

## 执行和数据边界

首次运行 Python 时按需从 jsDelivr 下载固定版本 Pyodide 0.29.3，在浏览器 Web Worker 中执行。代码不提交到判题服务器，无主机文件访问授权。每次新建 Worker，初始化最长 60 秒、运行最长 8 秒；stdout 最多 4000 字符。不要在练习代码或笔记中填写密钥。这里是学习环境，不是对恶意代码的完整安全隔离或正式考试系统。

本地测试是公开样例，不是 LeetCode 隐藏测试；不会自动判断运行复杂度。“LeetCode 已通过”是用户依原站确认的状态。没有连接会员账户或绕过付费内容，用户直接在原站使用会员。

进度、代码、笔记和个人背景先保存在当前浏览器 localStorage；配置云服务并登录、确认迁移后同步到私人账户。沿用旧版本键 `sprout-v1` 保留进度；新字段兼容旧备份。用户背景没有硬编码进源码。备份包含个人信息，发布作品前不要上传备份。

时间按 Europe/London 计算。每周计划调整修改对应星期的目标。答题和代码通过不自动增加学习分钟，需要如实记录。

这是规则驱动的本地 MVP：尚未接入联网 AI 导师、实时岗位抓取、每日最新论文抓取、自动提醒、自动申请或 GitHub 上传。

## 验证

运行 `node scheduler.cjs` 和 `python3 code-runner.py`。覆盖复习、阅读队列、旧备份兼容、非法数据、时区日期、页面生成、题单完整性、判分、错误反馈、原地修改、答案顺序和输出限制。

浏览器实际验证了正确 / 错误代码、无限循环 8 秒超时停止、论文笔记 / 自测完成条件、课程进度保留和本地状态持久化。用户入口为 localhost；127.0.0.1 是独立测试入口，两者存储互不影响。资料核对日期 2026-10-08，岗位和原站内容会变化。

## 在线使用与隐私

GitHub Pages 可直接在浏览器打开。学习进度存于当前网站的 localStorage，不上传服务器；换设备或从 localhost 转到线上请先在“计划与备份”导出，再在新网站导入。首次运行 Python 需要联网加载 Pyodide。公开发布版使用通用职业案例。

## 引导学习与 Agent 项目

[在线打开青云](https://jolinsjhp.github.io/qingyun/#today)，从今日配方进入填空、照例修改、独立重写并 Run。课程路线按前置知识安排李宏毅、Hugging Face、Andrew Ng；李沐、Karpathy、韩松作为进阶选修。每次视频控制在 20–30 分钟。

[Agent 项目](https://jolinsjhp.github.io/qingyun/#agent)包含 8 个引导关卡和可下载的 `agent-project.zip`。完整项目以活动筹备助手串联工具、资料检索、任务循环、停止条件和评测；使用模拟模型，无 API 费用，尚未连接真实 LLM。解压后运行 `python3 main.py` 与 `python3 -m unittest -v`。

## 账户与云同步

计划与备份页面提供邮箱链接登录。使用注册 Supabase 的组织成员邮箱（内置邮件服务限制）；其他邮箱需项目配置自有 SMTP。登录后首次选择使用本机或云端进度，迁移前保存双方副本。原 sprout-v1 键不变。保存后约 1 秒上传，其他设备约 15 秒或页面回到前台时接收；断网保留本机修改并重试。并发修改显示冲突，用户选择前不覆盖代码或笔记。未登录不上传。私人数据不进入公开 GitHub。

数据库已验证匿名拒绝、账号隔离、过期 revision 拒绝；云同步模拟测试覆盖断网重试和迁移。真实用户邮箱登录、现有成果迁移、两台物理设备验证仍需用户完成。
